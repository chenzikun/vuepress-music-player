# 播放器行为约束清单

改 `MusicPlayer.vue` / 歌单同步相关代码前，逐条对照。

## 歌单加载

| ID | 约束 |
|----|------|
| C1 | **同一路由 + 同一歌单**只应用一次，不重复 `audio.load()` / `requestPlay()` |
| C2 | `pageData` 未与 `route` 对齐时，**不**切换页面歌单 |
| C3 | 列表为空且 `pageData` 未对齐时，**仅一次** bootstrap 全局歌单 |
| C4 | `pageData` 对齐后，正确切换页面歌单 ↔ 全局歌单（SPA 切进/切出） |
| C5 | permalink 中 `=` / `_` 路径编码差异不影响对齐 |

## 换页播放

| ID | 约束 |
|----|------|
| C6 | 换到**相同歌单**（如两个都用全局列表的页面）时，**不中断、不从头重播** |
| C7 | 换到**不同歌单**时，从第一首开始；若 autoplay 开启且之前在播，则续播新歌单 |
| C8 | 用户手动暂停后换页，不因 sync 被动触发播放（除非新歌单页面级 autoplay 明确为 true 且歌单已变） |

## 初始化与触发

| ID | 约束 |
|----|------|
| C9 | 首次进入 autoplay **只触发一次**播放尝试 |
| C10 | 不用 `schedulePlaylistSync` 连发多次定时器；route 变化时最多 **一次** 延迟重试 |
| C11 | SSR 阶段不访问 `window` / `document` |

## 自动播放策略

| ID | 约束 |
|----|------|
| C12 | 浏览器拦截后，页面任意交互（点击/滚动/触摸/按键）可解锁 |
| C13 | 播放成功后移除手势监听 |

## 打包与渲染

| ID | 约束 |
|----|------|
| C14 | client 代码自包含在 `dist/client/`，不引用包外路径 |
| C15 | `ClientOnly` 包裹，避免 hydration mismatch |

## 快捷键

| ID | 约束 |
|----|------|
| C16 | `Space` 播放/暂停；`←` / `→` 上一首/下一首 |
| C17 | 焦点在 `input` / `textarea` / `select` / `contenteditable` 时不触发 |
| C18 | 快捷键监听随组件 mount/unmount 注册/移除 |
